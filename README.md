## Features

Expenses Tracker is a personal finance management application designed to help users monitor their spending and manage their budget effectively.

The system allows users to easily add, edit, and delete their daily income and expenses with custom categories, amount, and date. Users can set monthly budgets for each category and receive alerts to avoid overspending.

It features an interactive dashboard with visual charts and graphs that provides a clear overview of income vs. expenses, spending trends, and category breakdowns. Users can also filter transactions by date, category, and payment method, and generate detailed financial reports.

## Features Description

The Expenses Tracker is a web-based personal finance management system that helps users take control of their financial activities.

**Transaction Management:** The system enables users to record all income and expense transactions, organized by categories such as Food, Transportation, Bills, and more, with custom category support.

**Budget Planning:** Users can set monthly budget limits for each category. The system automatically tracks spending progress and notifies users when they are near or over their budget.

**Financial Analytics:** It provides a dynamic dashboard that visualizes financial data through pie charts, bar graphs, and monthly summaries, allowing users to easily understand their spending habits.

**Reports and History:** Users can view transaction history, search and filter records by date or category, and export financial reports for personal use.
